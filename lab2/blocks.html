  • Блочное представление

Блочное представление (block layout) — это модель, в которой каждый элемент страницы рассматривается как прямоугольный блок, занимающий место в потоке документа. Блочные элементы (например, div, p, section) начинаются с новой строки и растягиваются на всю доступную ширину по умолчанию.

Каждый блок состоит из четырёх частей: содержимого (content), внутренней отступки (padding), границы (border) и внешнего отступа (margin). Совокупность этих частей называется моделью блока (box model).

По умолчанию ширина блока вычисляется по свойству width, которое задаёт только размер содержимого. Чтобы в ширину были включены также padding и border, используется свойство box-sizing со значением border-box.

Положение блоков в потоке можно менять с помощью свойства display: значение block делает элемент блочным, inline — строчным, а none полностью скрывает элемент, освобождая занимаемое им место.
